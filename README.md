# wloc-spoofer

给 WLOC 定位模块配套使用的网页：在地图上选点、搜索地点、收藏坐标，再把选中的位置写入设备上的代理工具。另有地图链接解析 API，可供快捷指令调用。

本仓库提供网页和解析服务，不包含 WLOC 定位模块。网页本身不能更改系统 GPS，也不能保证各个 App 都采用写入的位置。

## 使用前准备

设备上需要安装并启用配套 WLOC 模块，开启 MITM、信任证书，并把 `gs-loc.apple.com` 加入 MITM 主机名。模块需拦截 `https://gs-loc.apple.com/wloc-settings/save`，处理写入、查询和清除操作；这是网页与本地模块约定的接口，不是 Apple 提供的设置 API。

打开网页后，点地图或拖动标记选择位置，点击「储存到设备」。可以查询、清除设备中的坐标，或把常用位置收藏在浏览器中。收藏使用 `localStorage`，换浏览器、换站点或清除网站数据后不会自动迁移。

网页和 API 共用 `src/coordinates.js` 中的直接坐标解析器，支持：

- `coordinate=` / `ll=` / `sll=`：纬度、经度
- 高德分享格式 `p=POIID,纬度,经度,名称,城市` 和 `q=纬度,经度,名称`
- `@纬度,经度`，以及经度在前的 `lnglat=` / `location=` / `center=`
- 带正负号的整数或小数坐标文本，逗号、`%2C` 或空格分隔

网页仍只提取文本中的坐标，不展开短链接、不调用解析 API，也不自动转换 GCJ-02 / BD-09。网页保留纯坐标文本的经纬度顺序判断：第一项绝对值大于 90、第二项在纬度范围时交换；两项都可作纬度时，按纬度、经度解释。API 的纯文本始终按纬度、经度解释。输入坐标需为有限数，纬度 −90 到 90、经度 −180 到 180；不合法的结果不会写入当前选点。

识别出参数不等于确认坐标系。高德、百度链接或地图图层可能采用不同坐标系，直接选点仍可能偏移；本次没有新增 BD-09 转换。

## 地图链接解析 API

```text
GET /api/parse?u=22.5000%2C113.9000&format=json
```

返回示例：

```json
{"lat":22.5,"lon":113.9,"name":""}
```

- `u`：地图链接、含链接的分享文字，或 `纬度,经度` 文本。放入查询参数前需要 URL 编码。
- `format=json`：返回 JSON；省略时返回 `lat=22.5&lon=113.9` 形式的文本。
- `cs=gcj`：按 GCJ-02 转为 WGS84；`cs=none`：不转换。省略时，保留旧 API 的参数启发式：识别为 `p` / `q` 或 `coordinate` / `ll` / `sll` 的输入会尝试 GCJ-02 转换，代码定义的境外范围保持原值。
- 该默认行为不证明所有 Apple Maps 链接都是 GCJ-02，也不通过域名验证坐标系。明确知道输入为 WGS84 时，应使用 `cs=none`；统一默认转换策略需单独评估。

API 支持上面的共享输入格式；响应字段仍为 `lat`、`lon`、`name`，经纬度保留到小数点后 6 位。不合法、越界或无法解析的输入返回 HTTP 422 和 `error` 字段。

输入没有直接可提取的坐标时，API 仍使用旧的短链接展开流程，最多发出 5 次请求。网页与 API 的短链展开、默认转换和纯文本顺序政策仍有上述区别。

## 本地开发

需要 Node.js 20 或更高版本和 npm。在仓库根目录运行：

```bash
npm install
npm run dev
```

`dev` 使用 `npx wrangler dev`，按终端提示打开本地地址。Cloudflare Workers 的入口是 `src/index.js`，Pages 的入口是 `functions/[[route]].js`。仓库另有单文件 `wloc-worker.js`；它不是当前 Wrangler 配置的入口，而是从 `src/` 生成的可独立部署版本，页面和 `/api/parse` 复用同一份源代码。修改源代码后运行 `npm run build`，不要手工改生成文件。单文件版本保留原有的 OPTIONS 响应和其他路径返回页面的行为。

构建和自动化测试不需要安装依赖，也不请求真实地图服务：

```bash
npm run build       # 生成单文件 Worker
npm test            # Node 测试 + 检查生成文件是否与源代码一致
npm run build:check # 只检查，无文件写入
```

测试覆盖直接解析、非法/边界坐标、API 字段、`cs` 兼容行为、模拟短链、页面脚本、模块写入参数和单文件一致性。部署与本地 Wrangler 调试仍需上述依赖。

## 数据和限制

地图图层使用第三方瓦片服务，搜索地点会请求 OpenStreetMap Nominatim；Leaflet 从 unpkg 加载。浏览器会向这些服务发送相应请求。解析 API 在需要展开链接时仍会由服务端请求输入的 URL；目前未新增域名白名单、总超时或响应体大小限制。不要把本次坐标校验当作服务端请求安全措施，公开部署前仍需单独评估这些限制及请求配额。

本地测试使用模拟环境，不代表已在 Cloudflare、Surge、Loon 或 Quantumult X 上实测。仓库仍没有配套模块的安装链接或版本要求；写入设备、MITM 拦截和不同 App 的定位效果需要与实际模块一起验证。
